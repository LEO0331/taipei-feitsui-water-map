# Civic Explorer attribution

The hexagonal SVG geometry originates in [Portfolio v3.0.1, merged PR #43](https://github.com/LEO0331/portfolio/pull/43), specifically `src/components/explorer/HexIsland.tsx`. The native-button scene/list, focus, filter and CSS patterns are adapted from [Real Estate Dashboard PR #6](https://github.com/LEO0331/taipei-real-estate-dashboard/pull/6) and its [navigation-entry refinement PR #8](https://github.com/LEO0331/taipei-real-estate-dashboard/pull/8).
